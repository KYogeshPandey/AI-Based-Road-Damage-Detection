# AI-Based Road Damage Detection - Project Documentation

This folder is the authoritative pre-development documentation for the project:

> AI-Based Multi-Class Road Damage Detection, Tracking, Unique Counting, and Visual Severity Analysis from Dashcam Video

Use these files to guide implementation with Codex. The earlier Perplexity research PDF remains useful as a literature-review archive, but it is not the implementation source of truth.

## Reading order

1. `PROJECT_PRD.md` - scope, requirements, acceptance criteria, and research questions.
2. `AGENTS.md` - rules Codex and contributors must follow.
3. `ARCHITECTURE.md` - modules, data contracts, event lifecycle, and repository structure.
4. `TECH_STACK.md` - selected tools and deliberately excluded alternatives.
5. `DATASET_GUIDELINES.md` - sampling, annotation, splitting, quality control, and hard negatives.
6. `WORKFLOW.md` - development and experiment workflow from raw video to final results.
7. `EVALUATION_PLAN.md` - metrics, ablations, ground truth, and result tables.
8. `PROJECT_ROADMAP.md` - milestone sequence and definition of done.
9. `ETHICS_AND_LICENSE.md` - privacy, responsible-use, dataset, and software licensing requirements.

## Decision priority

If two documents conflict, use this order:

1. `PROJECT_PRD.md`
2. `AGENTS.md`
3. `ARCHITECTURE.md`
4. Other project documents
5. Archived research PDF

Do not report experimental values until they have been generated by a reproducible run. All thresholds marked **provisional** must be tuned on the validation set and then frozen before the test set is evaluated.

## Fixed V1 decisions

| Area | Decision |
|---|---|
| Classes | D00 longitudinal crack, D10 transverse crack, D20 alligator crack, D40 pothole |
| Baseline detector | YOLOv8s |
| Proposed detector | YOLO26s; use YOLO26n only if compute is insufficient |
| Baseline tracker | ByteTrack |
| Primary tracker | BoT-SORT |
| Counting | Confirmed `DamageEvent` records, not frame detections and not raw track IDs |
| Severity | Relative visual severity measured in a fixed road measurement zone |
| Interface | CLI pipeline first; Streamlit dashboard after the pipeline is stable |
| Outputs | Annotated MP4, CSV, JSON, run manifest, metrics, and dashboard |
| Deferred | GPS, physical depth/size, segmentation, extra damage classes, mobile deployment |
